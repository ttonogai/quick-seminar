# コスト × 売上 分析ハンズオン用サンプルデータ

「OLA → MGN → Amazon Quick」セミナー Part 3（Amazon Quick で移行後の価値を見せる）で使うサンプルデータです。

## 想定シナリオ

中堅企業（オンプレの VM 約 60 台を AWS へ移行済み）を想定しています。AWS のコストデータ（CUR 相当）と、会計ソフトから出力した部門別月次売上を **Quick 上で掛け合わせ**、「コスト管理」から「経営に効く分析」へと踏み込むことがねらいです。

- 対象期間：2025-07 〜 2026-06（12 ヶ月）
- 通貨：円（CUR は固定レートで円換算した想定。売上と同じ通貨に揃えて掛け合わせしやすくしています）

> データはハンズオン用に生成した**サンプル（フィクション）**です。実在の企業・金額とは関係ありません。

## ファイル一覧

| ファイル | 内容 | 行数 |
|---|---|---|
| `AWSコスト明細.csv` | AWS のコストデータ（CUR 相当）。月 × システム × サービス単位 | 480 |
| `部門別売上.csv` | 会計ソフトから出力した想定の部門別月次売上 | 36 |
| `オンプレTCO参考.csv` | 移行前オンプレと AWS の年額 TCO 比較（補足資料用） | 7 |

## このデータに仕込んである「気づき」

ハンズオンで自然言語の質問や可視化から発見できるように、いくつかのストーリーを埋め込んでいます。

1. **開発・検証環境の常時稼働のムダ**：`開発・検証環境`（開発アカウント）の EC2 は 12 ヶ月間ずっと月 20 万円超が計上され続け、コストの変動がほとんどありません（＝利用量に応じた増減がない＝夜間・休日も含め 24/365 起動しっぱなし）。開発環境は本来、業務時間外は停止できるはず。「使っていない時間も課金され続ける」典型的なムダで、これはコストデータの変動の小ささから読み取れます。
2. **EC 事業部の高効率**：`EC事業部` は売上が 12 ヶ月で約 6,000 万→約 8,700 万円へ成長（12 月に繁忙期スパイク）。一方 IT コストの伸びは緩やかで、**売上あたり IT コストが改善**しています。
3. **ライトサイジングの効果**：`ERP基幹システム` は 2025-10 に本番のライトサイジングを実施し、EC2 コストが段階的に低下。
4. **売上のない部門のコスト**：`管理部門` `開発部門` `経営企画部門` は売上を持たない間接部門。コストの位置づけ（全社共通か、投資か）を議論する材料になります。

## 分析の質問例（Quick のチャット / ダッシュボードで）

- 先月（2026-06）最もコストが増えたシステムはどれ？前月比も教えて
- 部門別の AWS コストと売上を並べて、売上あたりの IT コストが高い部門を教えて
- 本番と開発で、環境別の月次コスト推移を比較して
- 開発アカウントのコストは、この 1 年でどう推移している？無駄がないか確認したい
- サービス別（EC2・RDS・S3・データ転送 …）のコスト内訳を円グラフにして
- EC 事業部の売上とコストの推移を重ねて、投資効率が改善しているか見せて
- オンプレ時代と比べて、AWS 移行後の年間 TCO はいくら削減できた？

## 本番環境での CUR 取り込み（参考）

このハンズオンではサンプル CSV を Quick に直接アップロードしていますが、実際の AWS 環境では CUR（AWS Cost and Usage Report）は **必ずいったん Amazon S3 に出力**され、そこから Quick が読み込みます。S3 から先は主に 2 通りです。

1. **S3 のマニフェスト経由で直接**：CUR を Quick（QuickSight）向けに設定すると S3 にマニフェスト（`...QuickSightManifest.json`）が生成され、Quick の S3 データソースでそのマニフェストを指定すれば Athena なしで直接取り込めます。小〜中規模向けの手軽な方法。
2. **Athena 経由**：リソース単位の粒度・Parquet・パーティション分割された大規模 CUR を扱う場合は「CUR → S3 → Athena（Glue）→ Quick」が定番。Cloud Intelligence Dashboards（CID/CUDOS）もこの構成です。

いずれも「S3 を介して」取り込む点が共通で、SPICE に取り込めば日次などで定期更新できます。
