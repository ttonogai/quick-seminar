# 問い合わせ本文サンプル

ハンズオンでフローの入力欄に貼り付ける、実際に届いた想定の問い合わせ本文です。
**サンプル 1 → 2 → 3 の順に試すと、フローの挙動の違いがわかります。**

---

## サンプル 1：情報がそろっている問い合わせ

```
情報システム部 御中

お世話になっております。経理部の田口です。

本日9時ごろから、経費精算システムにログインできません。
IDとパスワードを入力して「ログイン」を押すと、
「認証に失敗しました」という赤いメッセージが出て先に進めません。

パスワードは先週変更したばかりで、メモした通りに入力しています。
同じ部の2名にも確認しましたが、同様にログインできないようです。

月末の締め処理を今日中に終える必要があるため、
できるだけ早めにご対応いただけると助かります。

経理部 田口
```

**このサンプルで確認すること**：過去ケースに同じ事象が 3 件（CS-2026-0412 / CS-2026-0417 / CS-2026-0522）あります。類似ケースが提示され、解決策までたどり着けるかを見てください。

---

## サンプル 2：情報が足りない問い合わせ

```
印刷できません。急ぎです。よろしくお願いします。
```

**このサンプルで確認すること**：これだけでは分類も原因も特定できません。項目定義で判断できない項目に「要確認」が入るか、そして**依頼者に何を聞き返せばよいかが提示されるか**を見てください。実務でいちばん多いパターンです。

---

## サンプル 3：緊急度が高い問い合わせ

```
情報システム部 各位

製造部の第2ラインです。至急お願いします。

15時10分ごろから、ライン端末（管理番号 PC-2024-0088）の画面が
真っ暗になったまま操作できません。電源ボタンを長押ししても
反応がなく、再起動もできない状態です。

この端末が使えないと工程実績の登録ができず、
第2ラインを止めている状況です。現場に3名待機させています。

製造部 第2ライン 佐々木
```

**このサンプルで確認すること**：優先度が「緊急」と判定されるか、判定の根拠が示されるか。過去ケース CS-2026-0523（製造ライン端末の起動不可でライン停止）が類似ケースとして挙がるかを見てください。

---

## サンプル 4：複数の事象が混ざった問い合わせ（応用）

```
情報システム部 ご担当者様

営業部の丸山です。2点ご相談があります。

1点目です。先週から社内ポータルの表示が遅く、
特に午後になると申請一覧の画面が開くまで30秒ほどかかります。
隣の席の同僚は普通に使えているようで、私の端末だけかもしれません。

2点目です。新しく配属されたメンバー2名に、
CRMの参照権限を付けていただきたいです。
上長の承認は取得済みです。

お忙しいところ恐れ入りますが、ご確認をお願いいたします。

営業部 丸山
```

**このサンプルで確認すること**：1 通のメールに「障害」と「権限申請」という別カテゴリの依頼が混在しています。**ケースを分けて起票すべきと判断できるか**を見てください。カテゴリは主となる事象で 1 つ選ぶルールなので、記録を 2 件に分ける提案が出るのが望ましい挙動です。
