# 就業・勤怠運用 ハンズオン用サンプルデータ

「就業・勤怠運用：問い合わせ対応と自動チェック」シナリオ（エージェント型）で使うサンプルデータです。

## 想定シナリオ

フレックスタイム制とテレワークを導入している中堅企業の人事部を題材にしています。就業規則に関する問い合わせ対応、残業・36 協定リスクの分析、打刻不整合の検知と本人への通知を扱います。

勤怠管理はどの企業にも必ず存在する横断業務なので、業種を問わず提案できる導入の入り口になります。

> データはハンズオン用に生成した**サンプル（フィクション）**です。実際の労務判断には使用できません。

## ファイル一覧

| ファイル | 役割 | 内容 |
|---|---|---|
| `就業規則.md` | ナレッジ | 全 8 章。所定労働時間・フレックス・休暇・時間外労働など |
| `勤怠運用FAQ.md` | ナレッジ | 運用上のよくある質問（打刻漏れ・代休と振替休日・テレワーク・36 協定など） |
| `勤怠実績.csv` | 実績データ | 8 名 × 2025-01-06 〜 01-17 の日次実績 80 件 |
| `勤怠日次.csv` | ダッシュボード用 | 199 名 × 2024-01 〜 2026-05 の日次データ 2,400 件 |

`勤怠実績.csv` は個人単位の詳細確認用、`勤怠日次.csv` は全社傾向の可視化用です。期間と対象人数が異なるので、**2 つを結合しないでください**。

## 列の説明

### 勤怠実績.csv

| 列 | 説明 |
|---|---|
| 社員番号 / 氏名 / 部署 / 日付 | 対象者と対象日 |
| 出勤打刻 / 退勤打刻 | 打刻時刻（`HH:MM`）。休暇日は空欄 |
| 所定労働時間 / 実労働時間 / 残業時間 / 深夜残業時間 | いずれも `H:MM` 形式の時間表記。**小数ではありません** |
| 休暇種別 | 空欄 / 年次有給休暇 / 代休 / 午後半休 / 特別休暇 |
| 打刻漏れフラグ | なし / あり |
| 備考 | 遅刻理由、事前残業申請の有無、振替元の日付など |

> 時間が `H:MM` 形式なので、集計を依頼するときは「時間表記を分に換算して合計して」と指示すると精度が上がります。

### 勤怠日次.csv

`日付` `社員ID` `部門` `職位` `出勤` `退勤` `所定時間分` `残業時間分` `深夜時間分` `休暇種別` `有休消化日数` `テレワーク` `フレックス利用` `打刻漏れ` `36協定残量分` `プロジェクトID` `勤務地` `シフトパターン` `曜日` `業務カテゴリ`。時間はすべて**分単位の数値**なので、そのまま集計できます。

## このデータに仕込んである「気づき」

### 勤怠実績.csv（80 件）

1. **打刻漏れが 2 件**：うち 1 件は「出勤・退勤ともに打刻漏れ」で、実労働時間が算出できていません。FAQ の該当項目を根拠に、本人へ何を依頼すべきかを引き出せます。
2. **代休が 3 件、いずれも備考に振替元の日付がある**（`1/8の振替` など）。就業規則の代休と振替休日の違いを、実データと突き合わせて確認できます。
3. **事前残業申請の有無が備考に記録されている**：申請なしで残業している日がないか、規則と照合するチェックができます。
4. **遅刻の記録に理由が併記されている**（電車遅延・遅延証明あり）。就業規則の遅刻の扱いに照らした判断を問えます。

### 勤怠日次.csv（2,400 件・199 名）

- **テレワーク あり 1,027 / なし 1,373**。部門別・職位別の偏りを可視化できます
- **36 協定残量が分単位で入っている**ので、残量が少ない社員の抽出や、月内で上限に近づく人の早期警告が作れます
- `フレックス利用` `勤務地` `シフトパターン` `業務カテゴリ` があるため、働き方の実態と残業の関係を掛け合わせられます

## 質問例（エージェントのチャットで）

- 半日有給を取った日に残業した場合、残業代はどう計算されますか？就業規則の該当条文も教えてください
- 打刻漏れがある社員を抽出して、本人に送る確認依頼のメール文を作ってください
- 代休と振替休日の違いを、実績データの例を使って説明してください
- 残業時間が多い社員を上位から並べて、36 協定の上限に対するリスクを評価してください
- テレワークの利用率を部門別に比較して、偏りがあれば要因を推定してください

## 実務で使うときの注意

**労務判断の最終責任は人事担当者にあります。** 就業規則の解釈や割増賃金の計算は、法令改正や個別の労働契約に左右されます。このシナリオは「規則の該当箇所を素早く見つける」「チェック漏れを減らす」ことを支援するもので、判断そのものを代替するものではありません。
