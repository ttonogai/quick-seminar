# 保守サービス ハンズオン用サンプルデータ

「保守サービス：訪問計画と顧客対応を支援しよう」シナリオ（エージェント型）で使うサンプルデータです。

## 想定シナリオ

設備メーカーのアフターサービス部門を題材にしています。サービスエンジニアの訪問保守、SLA 管理、契約範囲の判断、契約更新提案を扱います。

全国規模でフィールド保守を展開している事業では本業そのものが題材になり、「自社の保守業務をどう効率化するか」を体感できます。保守サービスを提供しているあらゆる顧客への展開イメージにも直結します。

> データはハンズオン用に生成した**サンプル（フィクション）**です。実在の企業・設備・金額とは関係ありません。

## 列の説明

### 保守実績.csv

| 列 | 説明 |
|---|---|
| 対応ID / 顧客名 / 契約プラン | 識別と契約区分（プレミアム / スタンダード / ベーシック） |
| 対象設備 / 設備型式 | CNC 旋盤、射出成形機、マシニングセンタなど |
| 訪問日 / 対応区分 | 緊急対応 / 定期点検 / 計画修理 |
| 障害内容 / 対応内容 | 発生事象と実施した対処 |
| 作業時間（時間） | 作業に要した時間 |
| 部品交換有無 / 部品費用（円） / 作業費用（円） | 費用の内訳。契約内で無償の場合は 0 |
| 一次解決 | ○ / ×。× は再訪問が発生 |
| 担当エンジニア / 顧客満足度 / 備考 | 担当者と 5 段階評価 |

### 保守訪問日次.csv

`訪問日` `訪問ID` `顧客名` `業種` `契約プラン` `設備型式` `対応区分` `所要時間分` `部品費` `作業費` `総費用` `SLA達成` `一次解決` `再訪問` `担当エンジニア` `訪問距離km` `リモート判定` `対応難易度` `顧客満足度` `受付チャネル`。

`訪問距離km` と `リモート判定` があるため、**移動コストとリモート対応化の余地**を分析できます。

## このデータに仕込んである「気づき」

### 保守実績.csv（50 件・顧客 9 社）

対応区分は **緊急対応 28 / 定期点検 21 / 計画修理 1**。緊急対応が半数を超えており、**予防保全が機能していない**構図が見えます。

1. **一次解決 ○ 47 / × 3**：解決できなかった 3 件に共通点があるか（設備型式・プラン・担当者）を問えます
2. **顧客満足度 4 が 27 件、5 が 20 件、3 が 3 件**：評価 3 の案件で何が起きたのかを掘ると、満足度を落とす要因が特定できます
3. **プラン別の採算**：プレミアム 21 / スタンダード 21 / ベーシック 8。プランごとの作業時間・部品費・作業費を集計すると、**プランと実コストが見合っているか**が判断できます
4. **点検報告書の前回指摘事項**：油圧作動油の交換推奨など、次回対応が必要な項目が記載されています。実績と突き合わせると**フォローアップ漏れ**が見つかります

### 保守訪問日次.csv（1,500 件・2024-01 〜 2026-05）

- **SLA 達成 1,275 / 未達 225**（達成率 85.0%）。業種別・プラン別・エリア別の偏りを分析できます
- **再訪問 あり 250 件**（16.7%）。一次解決率の低い設備型式や難易度を特定できます
- 業種は 製造業 268 / IT 247 / 金融 137 / 電力 131 / 観光 131 / 公共 127 と分散しており、業種別の傾向比較が成立します

## 質問例（エージェントのチャットで）

- 次回の定期点検が必要な顧客と設備を、契約条件と訪問履歴から抽出してください
- 前回の点検で指摘した事項のうち、まだ対応されていないものはありますか？
- この障害は保守契約の範囲内ですか？除外事項に該当しないか確認してください
- 一次解決できなかった案件の共通点を分析して、対策を提案してください
- プラン別に作業時間と費用を集計して、料金設定が実コストに見合っているか評価してください
- 契約更新が近い顧客に対して、実績を根拠にしたプラン変更の提案文を作ってください
