## 1. 目的

## 3. オンサイト対応条件

### 3.1 対応エリアと出張費

| エリア区分 | 範囲 | 出張費（スタンダード以上は無料） |
|-----------|------|-------------------------------|
| エリアA | 当社拠点から50km以内 | 15,000円/回 |
| エリアB | 当社拠点から50〜100km | 25,000円/回 |
| エリアC | 当社拠点から100〜200km | 40,000円/回 |
| エリアD | 当社拠点から200km超 | 個別見積 |

### 3.2 オンサイト対応の流れ

1. 顧客からの障害連絡（電話・メール・Web）
2. コールセンターにて受付・一次切り分け
3. リモート診断（可能な場合）
4. オンサイト対応の要否判断
5. サービスエンジニアの派遣
6. 現地での故障診断・修理
7. 動作確認・顧客立会い確認
8. 作業報告書の提出（作業完了後3営業日以内）

### 3.3 エスカレーション基準

| レベル | 条件 | 対応 |
|--------|------|------|
| Level 1 | 通常故障 | サービスエンジニア1名で対応 |
| Level 2 | 復旧に4時間以上要する見込み | シニアエンジニアの追加派遣 |
| Level 3 | 復旧に8時間以上要する見込み | 技術マネージャーが現場指揮 |
| Level 4 | 顧客の生産ライン全停止 | 部長判断で全社リソース投入 |

## 4. 除外事項

### 4.1 保守対象外

以下の事項は保守契約の対象外とし、別途有償対応とする。

| 除外項目 | 理由 | 対応方法 |
|---------|------|---------|
| 天災（地震・台風・洪水等）による故障 | 不可抗力 | 都度見積による有償対応 |
| 顧客の不適切な使用による故障 | 仕様外使用 | 都度見積による有償対応 |
| 当社以外の第三者による改造・修理後の故障 | 責任範囲外 | 原則対応不可（個別協議） |
| 消耗品（刃具、フィルター、パッキン等）の交換 | 通常消耗 | 部品代実費 + 作業費 |
| ソフトウェアのバージョンアップ | 機能追加 | 別途ソフトウェア保守契約 |
| 設備の移設・据付 | 保守範囲外 | 別途工事見積 |
| 電源・エア・水等のユーティリティ異常に起因する故障 | 顧客設備 | 原因調査費のみ請求 |

### 4.2 免責事項

- 保守作業中の一時的な設備停止に伴う生産損失
- 部品の入手困難による修理期間の延長（最善努力義務）
- 顧客が推奨環境条件（温度・湿度・電源品質）を満たさない場合の性能低下
- 保守契約期間外に発生した故障

## 5. SLA（サービスレベル合意）

### 5.1 KPI定義

| KPI | 定義 | 目標値（プレミアム） | 目標値（スタンダード） |
|-----|------|--------------------|--------------------|
| 初動対応率 | 規定時間内に初動対応した割合 | 95%以上 | 90%以上 |
| オンサイト到着率 | 規定時間内に現地到着した割合 | 90%以上 | 85%以上 |
| 一次解決率 | 初回訪問で修理完了した割合 | 80%以上 | 75%以上 |
| 年間稼働率 | (総時間-停止時間)/総時間 | 99.0%以上 | 97.0%以上 |
| 顧客満足度 | アンケート5段階評価の平均 | 4.0以上 | 3.5以上 |

### 5.2 SLA未達時の対応

- 四半期レビューでSLA達成状況を報告
- SLA未達が2四半期連続した場合、改善計画を提出
- 年間稼働率保証未達の場合、未達分に応じた月額料金の減額（最大20%）

## 8. リモート監視サービス

### 8.1 サービス概要

| 項目 | 内容 |
|------|------|
| 対象プラン | プレミアム・スタンダード |
| 監視項目 | 設備稼働状態、異常アラート、主要パラメータ（温度・振動・圧力等） |
| 監視時間 | プレミアム: 24時間365日 / スタンダード: 平日8:00-20:00 |
| データ収集間隔 | 1分間隔（異常時はリアルタイム） |
| アラート通知 | メール＋SMS（プレミアムは電話連絡も） |
| データ保管期間 | 2年間（クラウドストレージ） |

### 8.2 リモート監視の導入要件

| 要件 | 内容 |
|------|------|
| ネットワーク | インターネット接続（固定IP推奨） |
| セキュリティ | VPN接続、ファイアウォール設定 |
| センサー | 当社指定のIoTセンサーキットの設置（初期費用別途） |
| ゲートウェイ | エッジコンピューティングデバイスの設置 |

### 8.3 リモート診断

- リモート監視データに基づき、異常の予兆を検知した場合、サービスエンジニアが電話またはリモートアクセスで診断を実施
- リモート診断で解決可能な場合は、オンサイト訪問なしで対応（プレミアム・スタンダード共に追加費用なし）
- リモート診断の結果、オンサイト対応が必要と判断した場合は、通常のオンサイト対応フローに移行
