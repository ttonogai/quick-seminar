## 1. 目的

本手順書は、社員が業務で使用するPC端末およびSaaSサービスの初期設定・接続・問い合わせに関する標準手順を定めるものである。

## 2. PC端末の初期設定

### 2.1 貸与端末の受領

1. 情報システム部より端末貸与通知メールを受信する
2. 指定日時に情報システム部窓口（本社8F）にて端末を受領する
3. 「端末貸与受領書」に署名・捺印し、控えを保管する

### 2.2 初回起動・セットアップ

| 手順 | 操作内容 | 所要時間目安 |
|------|----------|-------------|
| 1 | 電源投入後、社内ネットワーク（有線LAN）に接続 | 1分 |
| 2 | Windows Hello PINの設定（6桁以上） | 2分 |
| 3 | Azure AD認証（社員ID@kurogane-corp.co.jp） | 1分 |
| 4 | Intune自動ポリシー適用（再起動あり） | 15〜30分 |
| 5 | Microsoft 365アプリの自動インストール確認 | 10〜20分 |
| 6 | ウイルス対策ソフト（CrowdStrike Falcon）の稼働確認 | 3分 |
| 7 | VPNクライアント（GlobalProtect）の接続テスト | 5分 |

### 2.3 Wi-Fi接続設定

- **社内SSID**: `KUROGANE-CORP`（802.1X認証・証明書自動配布）
- **ゲストSSID**: `KUROGANE-GUEST`（来客用・業務利用不可）
- 社内Wi-Fiは証明書がIntuneから自動配布されるため、手動設定は不要
- 接続できない場合はヘルプデスクへ連絡（内線: 8800）

## 3. SaaSサービスの利用手順

### 3.1 利用可能なSaaSサービス一覧

| サービス名 | 用途 | ログイン方式 | 管理部門 |
|-----------|------|-------------|---------|
| Microsoft 365 | メール・Office・Teams | SSO（Azure AD） | 情報システム部 |
| Salesforce | CRM・営業管理 | SSO（Azure AD） | 営業企画部 |
| Slack | 社内チャット | SSO（Azure AD） | 情報システム部 |
| Confluence | ナレッジ管理 | SSO（Azure AD） | 情報システム部 |
| Jira | プロジェクト管理 | SSO（Azure AD） | 情報システム部 |
| Box | ファイル共有 | SSO（Azure AD） | 情報システム部 |
| freee会計 | 経費精算 | SSO（Azure AD） | 経理部 |
| SmartHR | 人事労務 | SSO（Azure AD） | 人事部 |
| Zoom | Web会議 | SSO（Azure AD） | 情報システム部 |

### 3.2 SSOログイン手順

1. 各サービスのログインページにアクセス
2. 「Microsoftアカウントでサインイン」を選択
3. 社員ID（`社員番号@kurogane-corp.co.jp`）を入力
4. Azure AD多要素認証（Microsoft Authenticator）で承認
5. 初回ログイン時はサービス固有の初期設定を実施

### 3.3 多要素認証（MFA）の設定

- 全SaaSサービスでMFA必須（2024年4月より全社適用）
- Microsoft Authenticatorアプリをスマートフォンにインストール
- 設定手順: Azure AD > セキュリティ情報 > 方法の追加 > Authenticatorアプリ
- バックアップ手段として電話番号（SMS）も登録すること

## 4. VPN接続手順

### 4.1 接続条件

- 社外ネットワークから社内システムにアクセスする場合はVPN必須
- VPNクライアント: Palo Alto GlobalProtect（Intune自動配布）

### 4.2 接続手順

1. タスクトレイのGlobalProtectアイコンをクリック
2. ポータルアドレス: `vpn.kurogane-corp.co.jp`
3. 社員IDとパスワードを入力
4. MFA認証（Authenticator）で承認
5. 「接続済み」表示を確認

### 4.3 VPN利用時の注意事項

- スプリットトンネル方式のため、社内システム以外の通信はVPNを経由しない
- VPN接続中はファイルサーバー（`\\fs01.kurogane-corp.local`）にアクセス可能
- 接続が不安定な場合は、一度切断して再接続を試みること

## 5. 問い合わせ手順

### 5.1 問い合わせ窓口

| 窓口 | 連絡先 | 対応時間 |
|------|--------|---------|
| ヘルプデスク電話 | 内線: 8800 / 外線: 03-XXXX-8800 | 平日 9:00〜18:00 |
| ヘルプデスクメール | helpdesk@kurogane-corp.co.jp | 24時間受付（対応は営業時間内） |
| チャットボット | Teamsアプリ「IT-Bot」 | 24時間（自動応答） |
| Jiraチケット | IT Support プロジェクト | 24時間受付 |

### 5.2 問い合わせ時の必要情報

問い合わせ時は以下の情報を準備すること：

1. **社員番号・氏名**
2. **端末管理番号**（端末裏面のシールに記載、例: `PC-2024-0001`）
3. **事象の詳細**（いつ・何をしたら・どうなったか）
4. **エラーメッセージ**（スクリーンショット推奨）
5. **緊急度**（業務停止/業務影響あり/軽微）

### 5.3 エスカレーションフロー

```
ユーザー → ヘルプデスク（1次対応）
  → 解決できない場合 → インフラチーム / アプリチーム（2次対応）
    → 解決できない場合 → ベンダーサポート / 情報システム部長判断（3次対応）
```

### 5.4 対応目標時間（SLA）

| 緊急度 | 初回応答 | 解決目標 |
|--------|---------|---------|
| 業務停止 | 15分以内 | 4時間以内 |
| 業務影響あり | 30分以内 | 8時間以内 |
| 軽微 | 2時間以内 | 3営業日以内 |

## 6. よくある質問（FAQ）

### Q1. パスワードを忘れた場合は？
Azure ADセルフサービスパスワードリセット（https://passwordreset.microsoftonline.com）から再設定可能。MFA登録済みであることが前提。

### Q2. 端末が起動しない場合は？
電源ボタン長押し（10秒）で強制シャットダウン後、再起動を試みる。改善しない場合はヘルプデスクへ連絡し、代替端末の貸出を依頼する。

### Q3. SaaSサービスにログインできない場合は？
ブラウザのキャッシュ・Cookieをクリアし、InPrivateモードで再試行する。それでも解決しない場合はヘルプデスクへ連絡。

### Q4. 新しいSaaSサービスの利用申請は？
Jiraの「IT Support」プロジェクトで「SaaS利用申請」チケットを起票する。上長承認後、情報システム部がアカウントを発行する。

## 7. 端末の日常メンテナンス

### 7.1 Windows Update の管理

- Windows Updateは情報システム部がIntune経由で配信スケジュールを管理
- 毎月第2火曜日（米国時間）にMicrosoftがセキュリティ更新プログラムを公開
- 当社では公開後3営業日以内にステージング端末でテスト、問題なければ全社配信
- 更新プログラムの適用状況はIntuneコンソールで確認可能
- 再起動が必要な場合、業務時間外（18:00以降）に自動再起動が実行される
- 緊急セキュリティパッチ（CVSS 9.0以上）は即日配信の場合あり

### 7.2 ディスク容量の管理

| 状態 | 残容量 | 対応 |
|------|--------|------|
| 正常 | 50GB以上 | 対応不要 |
| 注意 | 20〜50GB | 不要ファイルの整理を推奨 |
| 警告 | 10〜20GB | ヘルプデスクに相談 |
| 危険 | 10GB未満 | 即時ヘルプデスクに連絡 |

ディスク容量を確保するための推奨手順：
1. ダウンロードフォルダの不要ファイルを削除
2. ごみ箱を空にする
3. ブラウザのキャッシュをクリア
4. 不要なアプリケーションをアンインストール（情シス部に確認の上）
5. 大容量ファイルはBoxにアップロードしローカルから削除

### 7.3 バッテリー管理（ノートPC）

- バッテリー残量が20%以下になったら充電を推奨
- 常時ACアダプター接続はバッテリー劣化の原因となるため、週に1回は放電→充電サイクルを実施
- バッテリー健全性が80%以下になった場合はヘルプデスクに連絡（交換対象）
- バッテリー健全性の確認方法：
  - Windows: `powercfg /batteryreport` コマンドで確認
  - Mac: Optionキーを押しながらAppleメニュー → システム情報 → 電源

## 8. セキュリティに関する注意事項

### 8.1 フィッシングメールへの対応

不審なメールを受信した場合の対応手順：

1. メール内のリンクをクリックしない
2. 添付ファイルを開かない
3. 送信者のメールアドレスを確認（ドメインが正規のものか）
4. 不審と判断した場合、Outlookの「フィッシングとして報告」ボタンをクリック
5. 判断に迷う場合はヘルプデスクに転送して確認を依頼

### 8.2 パスワード管理

- 全パスワードは1Password Businessで管理すること
- ブラウザのパスワード保存機能は使用禁止（Intuneポリシーで無効化済み）
- パスワードの使い回しは厳禁
- 1Passwordのマスターパスワードは16文字以上を推奨
- パスワードの共有が必要な場合は1Passwordの共有Vaultを使用

### 8.3 端末の物理セキュリティ

- 離席時は必ず画面をロック（Windows: `Win + L`、Mac: `Ctrl + Command + Q`）
- 外出時はPCを車内に放置しない
- カフェ等の公共の場では画面にプライバシーフィルターを装着
- 端末の紛失・盗難が発生した場合は直ちにヘルプデスクに連絡（内線8800）

### 8.4 外部デバイスの接続制限

| デバイス種別 | 接続可否 | 備考 |
|-------------|---------|------|
| USBマウス・キーボード | ○ 許可 | HID デバイスのみ |
| USBストレージ（メモリ・HDD） | × 禁止 | CrowdStrikeでブロック |
| 外部モニター（HDMI/USB-C） | ○ 許可 | |
| プリンター（USB接続） | △ 要申請 | ネットワークプリンター推奨 |
| スマートフォン（充電のみ） | ○ 許可 | データ転送はブロック |
| Bluetoothデバイス | ○ 許可 | ヘッドセット・マウスのみ |

## 9. リモートワーク時の注意事項

### 9.1 推奨ネットワーク環境

| 項目 | 推奨値 |
|------|--------|
| 下り速度 | 50Mbps以上 |
| 上り速度 | 10Mbps以上 |
| レイテンシ | 50ms以下 |
| 接続方式 | 有線LAN推奨（Wi-Fi 5以上も可） |

### 9.2 リモートワーク時のセキュリティ

- 社内システムへのアクセスは必ずVPN経由で行うこと
- 公共Wi-Fi（カフェ・ホテル等）での業務は原則禁止（やむを得ない場合はVPN必須）
- 家族や同居人がPCを操作できない環境で作業すること
- Web会議時は周囲に機密情報が漏れないよう注意（イヤホン使用推奨）
- 業務終了後はVPNを切断し、PCをシャットダウンすること

### 9.3 Web会議のベストプラクティス

- 会議開始5分前にZoom/Teamsの接続テストを実施
- カメラ・マイクの動作確認を事前に行う
- 背景はぼかし機能またはバーチャル背景を使用
- 画面共有時は不要なウィンドウを閉じる（通知もオフに）
- 録画が必要な場合は参加者全員の同意を得ること

## 10. トラブルシューティングガイド

### 10.1 PCが起動しない場合

```
1. 電源ケーブル/ACアダプターが接続されているか確認
2. 電源ボタンを10秒間長押しして強制シャットダウン
3. 30秒待ってから再度電源ボタンを押す
4. それでも起動しない場合 → ヘルプデスクに連絡（代替端末を手配）
```

### 10.2 インターネットに接続できない場合

```
1. Wi-Fiアイコンの状態を確認（接続済み/未接続）
2. Wi-Fiを一度オフにして再度オンにする
3. 他のデバイス（スマートフォン等）でインターネット接続を確認
4. VPN接続中の場合、一度切断して再接続
5. PCを再起動する
6. 改善しない場合 → ヘルプデスクに連絡
```

### 10.3 SaaSサービスにログインできない場合

```
1. ブラウザのキャッシュ・Cookieをクリア
2. InPrivate/シークレットモードで再試行
3. 別のブラウザ（Edge/Chrome）で試行
4. Azure ADのセルフサービスパスワードリセットを試行
5. MFA（Authenticator）の時刻同期を確認
6. 改善しない場合 → ヘルプデスクに連絡
```

### 10.4 プリンターで印刷できない場合

```
1. プリンターの電源が入っているか確認
2. PCとプリンターが同じネットワークに接続されているか確認
3. 印刷キューに滞留しているジョブがないか確認
4. プリンタードライバを再インストール
5. 改善しない場合 → ヘルプデスクに連絡
```

### 10.5 Teamsの音声・映像トラブル

```
1. Teamsの設定 → デバイス で正しいマイク・スピーカー・カメラが選択されているか確認
2. OS側の音声設定を確認（音量がミュートになっていないか）
3. 他のアプリがマイク・カメラを使用していないか確認
4. Teamsを再起動
5. PCを再起動
6. 改善しない場合 → ヘルプデスクに連絡
```

## 11. 端末の返却・交換手順

### 11.1 端末返却が必要なケース

- 退職時
- 端末の更新（新端末への交換）
- 長期休職（3ヶ月以上）
- 部門異動に伴う端末種別変更

### 11.2 返却前の準備

1. 個人データのバックアップ（Box/OneDriveに保存）
2. ブラウザのブックマーク・パスワードが1Passwordに保存されていることを確認
3. ローカルに保存されている業務ファイルをBoxにアップロード
4. メールの重要なデータがExchange Onlineに同期されていることを確認
5. 端末の初期化は情報システム部が実施するため、自分で行わないこと

### 11.3 返却手順

1. 情報システム部窓口（本社8F）に端末を持参
2. ACアダプター・付属品を一緒に返却
3. 「端末返却確認書」に署名
4. 情報システム部がデータ消去・初期化を実施
5. 退職の場合、端末返却をもってIT資産の返却完了とする
